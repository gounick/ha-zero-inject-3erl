# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/gounick/ha-zero-inject-3erl/security/advisories/new)
rather than a public issue.

## Scope

This integration drives a physical relay from the 3ERL curtailment signal.
Issues that could cause the relay to stay in a wrong state (e.g. missed
curtailment or unwanted curtailment) are in scope.

The supported version is the latest release only.
