# Politique de sécurité

## Signaler une vulnérabilité

Veuillez signaler les vulnérabilités en privé via les
[avis de sécurité GitHub](https://github.com/gounick/ha-zero-inject-3erl/security/advisories/new)
plutôt que par un ticket public.

## Périmètre

Cette intégration commande un relais physique à partir du signal de bridage 3ERL.
Les problèmes susceptibles de laisser le relais dans un mauvais état — par exemple
un bridage manqué ou un bridage indésirable — sont concernés.

Seule la dernière version publiée est prise en charge.
