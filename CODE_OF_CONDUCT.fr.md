# Code de conduite

Ce projet applique le [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1. La version anglaise fait foi : [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

La traduction française officielle est publiée sur
<https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/>.

## En résumé

- Nous nous engageons à faire de la participation à ce projet une expérience
  sans harcèlement pour tout le monde.
- Les comportements attendus : empathie, respect des opinions divergentes,
  feedback constructif, responsabilité et attention portée à la communauté.
- Les comportements inacceptables : propos ou images sexualisés, trolling,
  attaques personnelles, harcèlement, publication d’informations privées.
- Les cas d’abus peuvent être signalés aux responsables via un
  [rapport privé](SECURITY.md) sur ce dépôt ; ils seront examinés rapidement
  et équitablement, dans le respect de la vie privée du plaignant.
- Les sanctions possibles suivent les lignes directrices du Contributor
  Covenant : correction, avertissement, bannissement temporaire ou définitif.
